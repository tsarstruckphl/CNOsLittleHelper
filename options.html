How to install update:
  1. Click Download Release Package (.zip) above and extract the file to a folder.
  2. Navigate to chrome://extensions/ in a browser tab.
  3. Turn on Developer mode using the toggle switch in the top-right corner.
  4. Click Load unpacked in the top-left and select your extracted folder.
