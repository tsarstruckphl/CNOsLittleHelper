Custom Sharp Books

Choose the books you trust as "sharp" and how much each counts. The extension uses them to work out a fair value for a line. A league's set is used first, then its sport's, then All; at each of those, a set for the line's market type (player markets, the ones starting with "Player", or non-player markets) comes before one for all markets. If no set fits a line, Sharp FV isn't offered for it. If a chosen book has no line, is missing a side, or (for exchanges) is under its minimum liquidity, its weight is shared out among the other books in proportion.

Custom Sharp Book Devigging is turned off. You can set it up here, then turn it on in the extension's Settings page.
